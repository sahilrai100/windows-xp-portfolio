# Windows XP Portfolio

The Windows XP-themed personal portfolio of **Sahil Rai**, a backend-focused Software Engineer, built with Next.js. This project recreates the nostalgic feel of Windows XP as an interactive web experience.

## Features

- Authentic Windows XP boot screen with loading animation
- Draggable windows with minimize, maximize, and close functionality
- Functional Start Menu with All Programs flyout
- Desktop icons with double-click to open
- Right-click context menus
- Real-time clock in the taskbar
- Log off and shutdown functionality

### Applications

- **My Computer** - System information display
- **About Me** - Personal profile and background
- **My Projects** - Portfolio of development work
- **Skills** - Technical skills and expertise
- **Contact** - Contact form and social links
- **Internet Explorer** - Web browser with search functionality
- **Notepad** - Text editor
- **Calculator** - Functional calculator with memory
- **Minesweeper** - Classic minesweeper game
- **Solitaire** - Klondike solitaire card game
- **Paint** - Drawing application with tools and color palette
- **Snake** - Classic snake game
- **Help and Support** - Usage guide
- **Recycle Bin** - Displays deleted items
- **Run** - Command dialog to launch applications

## Tech Stack

- Next.js 16
- React 19
- TypeScript
- CSS (custom Windows XP styling)

## Getting Started

### Prerequisites

- Node.js 18 or higher
- npm, yarn, pnpm, or bun

### Installation

```bash
git clone https://github.com/sahilrai100/windows-xp-portfolio.git
cd windows-xp-portfolio
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build

```bash
npm run build
npm start
```

## Deployment
